# ATEX IT — Rediseño editorial 2026

Sitio estático de ATEX IT con una dirección visual editorial, responsive y orientada a presentar proyectos reales.

## Ejecutar localmente

Puedes abrir `index.html` directamente o levantar un servidor local:

```bash
python -m http.server 8000
```

Después visita `http://localhost:8000`.

## Archivos principales

- `index.html`: estructura, contenido, SEO y accesibilidad.
- `css/styles.css`: sistema visual completo y responsive.
- `js/events.js`: menú móvil, navegación activa, animaciones, formulario y chatbot.
- `img/`: logotipos y capturas de proyectos.

## Integraciones conservadas

- Formulario: Formspree.
- Contacto: WhatsApp y correo.
- Proyectos: Mariachi Nuevo Amanecer y Mariachi App V2.
- Redes: Facebook e Instagram.

## Publicación

El proyecto puede publicarse directamente en GitHub Pages, Hostinger, Netlify o Vercel como sitio estático. El archivo `CNAME` se conserva para el dominio configurado.
